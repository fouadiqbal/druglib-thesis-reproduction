# Conference paper

`main.tex` is an IEEEtran conference-paper draft built from the saved outputs in
`results/`. It keeps the official UCI split as the primary analysis and labels all
fold-contained CV, overlap diagnostics, ablations, confidence intervals, and McNemar
testing as supplementary. The venue is intentionally a placeholder. Compile with a
local TeX installation using `pdflatex main.tex` from this directory; the figures are
referenced from `../figures/`.
